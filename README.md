# Simple Node.js App

A minimal functional Node.js application using Express.

## Requirements

- Node.js 18 or newer
- npm

## Run

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```

Open:

http://localhost:3000

## Development

Run with Node's built-in watch mode:

```bash
npm run dev
```

## API

The application exposes:

`GET /api/hello`

Example response:

```json
{
  "message": "Hello from Node.js!",
  "timestamp": "2026-09-06T20:00:00.000Z"
}
```
